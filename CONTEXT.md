# MeetHub: глоссарий

## Трекинг MR

**Доска MR** — одно закреплённое rich-сообщение (Bot API 10.1) в группе обсуждений подключённого канала. Бот редактирует его на месте и показывает открытые MR команды таблицами Markdown; reference каждого MR — гиперссылка. Не путать со сводкой дейлика.

**Участник** — член команды: пользователь GitLab с корректным Telegram username в поле Twitter профиля. Бот получает подпись автоматически; состав команды общий для всех подключённых каналов. Ручная конфигурация в меню `/start` отключена, прежние записи сохранены, но не используются. Не путать с игнор-листом.

**Командный MR** — MR, который попадает на доску MR. Он открыт, не Draft, у него назначен хотя бы один ревьювер, а автор или хотя бы один ревьювер — участник. Смерженные и закрытые MR сразу убираются с доски.

**Статус ревьювера** — reviewer state из GitLab для пары «MR × ревьювер»: `unreviewed`, `reviewed`, `requested_changes`, `approved`. Бот берёт его из GitLab и не хранит ручных статусов.

**Мяч** — кто сейчас должен действовать по MR:
- `unreviewed`, `reviewed` → мяч на ревьювере;
- `requested_changes` → мяч на авторе;
- `approved` → мяча нет.

**Повторное ревью** — состояние `unreviewed` после Re-request review от автора, когда этот ревьювер уже смотрел MR. На доске отмечается 🔁.

**Разделы доски** (MR попадает в раздел по худшему статусу ревьюверов):
1. «Ждёт ревью» — хотя бы один ревьювер в `unreviewed` или `reviewed`.
2. «Ждёт правок автора» — хотя бы один ревьювер в `requested_changes`.
3. «Апрув, ждёт merge» — все ревьюверы в `approved`.

**Вид доски** — per-channel настройка группировки строк доски: «по мячам», «по ревьюверу» или «по проекту». Владелец меняет кнопкой-циклом в меню канала.

**«По мячам»** — вид по умолчанию: три раздела доски, внутри каждого одна таблица, строки по возрасту ожидания.

**«По ревьюверу»** — вид, где раздел «Ждёт ревью» разбит на блоки «X смотрит» по ждущим ревьюверам: MR с несколькими ждущими попадает в блок каждого; «Ждёт правок автора» — блоки «Y должен» по авторам; «Апрув» — единая таблица.

**«По проекту»** — вид, где на каждый проект одна таблица со всеми его MR, мяч показан бейджем в строке.
